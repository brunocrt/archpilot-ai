# Codex Instructions for ArchPilot AI

## Project goal
ArchPilot AI is an enterprise architecture copilot. It lets users upload system documentation, chunk and embed it, retrieve relevant context, and answer questions with citations.

## Tech stack
- Backend: Python, FastAPI, SQLAlchemy
- Frontend: Next.js 14, TypeScript
- Database: PostgreSQL
- Deployment: Docker Compose
