# Public Architecture Reference Catalog

Use this catalog as a lightweight pointer document or download the linked materials into this folder before running the seed script.

## C4 Model

Source: https://c4model.com/

The C4 model is a public architecture documentation approach for visualizing software architecture through system context, container, component, and code diagrams.

## arc42

Source: https://arc42.org/download

arc42 is a software architecture documentation template with sections for goals, constraints, context, building blocks, runtime view, deployment view, quality requirements, risks, and decisions.

## Azure Well-Architected Framework

Source: https://learn.microsoft.com/en-us/azure/well-architected/what-is-well-architected-framework

The Azure Well-Architected Framework organizes architectural guidance around reliability, security, cost optimization, operational excellence, and performance efficiency.

## NIST SP 800-160

Source: https://csrc.nist.gov/pubs/sp/800/160/v1/r1/final

NIST SP 800-160 provides systems security engineering guidance for trustworthy secure systems across the system life cycle.
